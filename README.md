# ComfyUI-BatchMediaHub-
ComfyUI Minimax H3 批量素材中心节点（支持外部拖入图片/视频/音频，支持排序，支持开关）

一个节点管 9 张参考图 / 3 段参考视频 / 3 段参考音频的**批量上传、预览、逐格开关**，
专为 MiniMax H3 `MiniMaxH3ReferenceToVideo` 的 15 路参考输入设计。
节点名 `BatchMediaHub`，菜单分类 `Batch/素材`，显示名「批量素材中心（9图/3视频/3音频）」。

## 安装

1. 把 `ComfyUI-BatchMediaHub` 整个文件夹放进 `ComfyUI/custom_nodes/`
2. `pip install -r requirements.txt`（Pillow / numpy / torchaudio / av，缺 `av` 时视频会解码失败）
3. 重启 ComfyUI（模型定义和上传路由都在启动时注册，改代码后必须重启）
4. 装完后浏览器页面按 **Ctrl+F5** 硬刷新一次，前端 JS 才会重新加载

## 界面与操作（全部在画布里）

| 操作 | 结果 |
| --- | --- |
| 从电脑**拖文件到某一格** | 直接上传进这一格（拖到空位就填空位、拖到已有素材就是替换）；拖拽悬停时格子会亮蓝框，松手即上传；一次可拖多个文件，多出来的按顺序往后填 |
| 点空格子 | 打开**系统文件选择器**（多选，按顺序填入空位）；不再有自定义导入弹窗 |
| 点已填的**视频/音频**格子 | **画布内直接播放**（不弹窗、无 ▶/⏸ 角标）：格子里放实时画面/频谱波形 + 底部进度条；再点一次暂停；同一类型同时只播一个 |
| 点已填的**图片**格子 | 什么都不弹，图片本身就在格子里显示 |
| 右键**某一格** | 单格菜单：打开详情/播放窗口、替换、停用/启用、清空（空格则是「上传素材到该格」） |
| 点右上圆点 | 启用 / 停用（绿=启用、灰=停用；**文件保留**，只是输出 `None`）；命中半径 16px，且**空格子点圆点等于点格子（进选择器）**，不会误切换；停用会顺手停掉该格正在播的视频/音频 |
| 从已有素材的格子**拖到另一格**（同类型） | 两格**互换位置**（画面、开关状态、标签一起换），松手落在同类另一格即生效，拖回来可换回去；跨类型（图↔视频）不互换 |
| 点左上 × | 清空这一格（同样认 14px 精确命中，并停止播放该格）；**空格不显示 ×** |
| 右键节点空白处 | 批量上传图片/视频/音频（系统选择器，可多选）、全部启用、全部停用（保留文件）、清空全部素材、视频帧数上限（25/49/73/97/121） |
| Esc / 点遮罩 | 关掉详情/播放窗口（只有右键菜单里主动打开时才有） |
