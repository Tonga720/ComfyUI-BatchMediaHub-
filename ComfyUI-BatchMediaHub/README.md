# ComfyUI-BatchMediaHub

一个节点管 9 张参考图 / 3 段参考视频 / 3 段参考音频的**批量上传、预览、逐格开关**，
专为 MiniMax H3 `MiniMaxH3ReferenceToVideo` 的 15 路参考输入设计。
节点名 `BatchMediaHub`，菜单分类 `Batch/素材`，显示名「批量素材中心（9图/3视频/3音频）」。

## 安装

1. 把 `ComfyUI-BatchMediaHub` 整个文件夹放进 `ComfyUI/custom_nodes/`
2. `pip install -r requirements.txt`（Pillow / numpy / torchaudio / av，缺 `av` 时视频会解码失败）
3. 重启 ComfyUI（模型定义和上传路由都在启动时注册，改代码后必须重启）
4. 装完后浏览器页面按 **Ctrl+F5** 硬刷新一次，前端 JS 才会重新加载

## 界面与操作（全部在画布里）

| 操作 | 结果 |
| --- | --- |
| 从电脑**拖文件到某一格** | 直接上传进这一格（拖到空位就填空位、拖到已有素材就是替换）；拖拽悬停时格子会亮蓝框，松手即上传；一次可拖多个文件，多出来的按顺序往后填 |
| 点空格子 | 打开**系统文件选择器**（多选，按顺序填入空位）；不再有自定义导入弹窗 |
| 点已填的**视频/音频**格子 | **画布内直接播放**（不弹窗、无 ▶/⏸ 角标）：格子里放实时画面/频谱波形 + 底部进度条；再点一次暂停；同一类型同时只播一个 |
| 点已填的**图片**格子 | 什么都不弹，图片本身就在格子里显示 |
| 右键**某一格** | 单格菜单：打开详情/播放窗口、替换、停用/启用、清空（空格则是「上传素材到该格」） |
| 点右上圆点 | 启用 / 停用（绿=启用、灰=停用；**文件保留**，只是输出 `None`）；命中半径 16px，且**空格子点圆点等于点格子（进选择器）**，不会误切换；停用会顺手停掉该格正在播的视频/音频 |
| 从已有素材的格子**拖到另一格**（同类型） | 两格**互换位置**（画面、开关状态、标签一起换），松手落在同类另一格即生效，拖回来可换回去；跨类型（图↔视频）不互换 |
| 点左上 × | 清空这一格（同样认 14px 精确命中，并停止播放该格）；**空格不显示 ×** |
| 右键节点空白处 | 批量上传图片/视频/音频（系统选择器，可多选）、全部启用、全部停用（保留文件）、清空全部素材、视频帧数上限（25/49/73/97/121） |
| Esc / 点遮罩 | 关掉详情/播放窗口（只有右键菜单里主动打开时才有） |

格子外框为**直角方边**，没有圆角。

播放全靠画布内的一条 `requestAnimationFrame` 循环按需重绘（有播放器时才跑，全停即退出），
不会让画布常驻 60fps；音频用 WebAudio 频谱驱动波形，所以波形会随声音跳动。

停用或空格输出 `None`，等价于「旁路 LoadImage + SetNode」，H3 的参考输入本身允许缺省。

## 输出（15 路）

| 输出 | 类型 | 接到 265 `MiniMaxH3ReferenceToVideo` |
| --- | --- | --- |
| 图1–图9 | IMAGE | `ref_images.ref_image_0..8` |
| 视频1–视频3 | IMAGE（帧序列） | `ref_videos.ref_video_0..2` |
| 音频1–音频3 | AUDIO | `ref_audios.ref_audio_0..2` |

`ref_video_audios.*` 为空即可（不影响 H3 画面参考）。

## 数据存放

- 每个格子的状态是一段 JSON，存在节点唯一的 `state` 控件里（**界面隐藏、随工作流保存**），
  结构：`{"v":1,"max_video_frames":121,"slots":{"image":[{"file":"x.jpg","on":true,"meta":{...}}],...}}`
- 视频帧数上限也在这个 JSON 里（`max_video_frames`），用右键菜单改，默认 121。
- 素材落到 `ComfyUI/input/batch_media/`，同名自动加 `_1/_2` 不覆盖；
  缩略图在 `input/batch_media/_thumbs/`，前端用 ComfyUI 自带的 `/view` 读取。
- 上传接口：`POST /batch_media/upload`（multipart，字段名 `files`/`file`/`images`），
  返回 `{ok, files:[{name,kind,size,thumb,width,height,frames,duration,sample_rate}], skipped}`。

## 已验证环境

- ComfyUI **0.45.2** + 前端 1.58.5（秋叶整合包 v3.2，torch 2.9.1+cu130，RTX 2060 SUPER）
- 实测通过：节点注册（15 输出）、上传（图片+音频同请求）、图片/音频/视频解码、
  `run` 输出与 `None` 语义、`IS_CHANGED` 重跑判定、画布面板绘制、开关圆点点击、右键菜单。

## 为什么开关不容易误触

- 开关命中区是**半径 16px 的圆点**（视觉半径 8px），清除 × 是半径 14px；格子其余区域一律走「导入 / 播放」。
- 只有**已经有文件**的格子才响应开关和 ×；空格子的圆点恒为灰色、左上不画 ×，点圆点等于点格子（进选择器），所以「空的」一眼能看出来。
- 松手时的落点直接判定：拖到同类另一格就互换，不需要画面上出现拖影；落在原位才算点击。

## 常见遮挡

- ComfyUI-Manager 的「需要升级 ComfyUI-Manager」提示条会浮在画布右上，正好盖住节点顶部两行，
  此时点圆点/×会落到提示条上（表现为「点了没反应」）。点掉提示条右上角关闭再操作即可。

## 已知限制

- **torchaudio 2.9 的 `load` 需要 torchcodec**，多数整合包没装，所以音频解码优先走 **PyAV**，
  torchaudio 只作旧版本兜底。音频不需要额外装 torchcodec。
- 视频解码 PyAV 优先、OpenCV 兜底；两者都没有时视频格会报「视频解码失败」。
- 前端是一个文件一个请求上传，单文件仍受 ComfyUI 请求体上限约束（默认 100MB）；更大的视频建议先转码或切段。
- 槽位固定 9/3/3（对齐 H3 输入结构），不可配置。
- 新前端（1.58+）的 DOM widget 会在节点里占一行，本节点已用 `type="hidden"` + 隐藏 DOM 元素压掉；
  若未来前端改版出现一条空白控件行，改 `web/js/batch_media_hub.js` 里 `drawHub()` 顶部那两行即可。
